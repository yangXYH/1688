# 采货台 Chrome 可见自动问答插件

完整操作步骤、模型配置、并发说明与排障见 [中文使用手册](https://github.com/yangXYH/1688/blob/main/docs/chrome-extension-guide.zh-CN.md)。

1. 启动本机服务：源码目录运行 `pnpm build`、`pnpm ui`，默认端口 4173。
2. 在你常用的 Google Chrome 中登录 1688。无需导出 Cookie，无需使用 CLI 的浏览器登录。
3. 在 Chrome 地址栏输入 `chrome://extensions`，打开「开发者模式」，点击「加载已解压的扩展程序」，选择本目录（内含 manifest.json）。ZIP 包需先解压。
4. 固定「采货台 · 可见自动问答」插件，点击图标打开侧栏。连接本机服务；核对侧栏显示的买家账号与旺旺页面顶部一致。已有会话记录时要求使用同一买家账号，避免串号。
5. 在侧栏输入关键词，点击「打开搜索」。结果来自当前 Chrome 的真实 1688 搜索页；默认选择前 5 件，也可勾选其他商品。
6. 查看对象、固定问题和澄清话术，勾选授权，点击「开始本批自动问答」。每家供应商打开一个真实旺旺标签页；标签页保留，你可以看到实际填写和发送。

## 手动回复与暂停

- 点击侧栏的「打开真实旺旺」切换到对应会话。
- 点击「接管此家」/网页右上角「暂停并接管」，或直接点击真实会话页面、在输入框打字，即暂停该家；其余会话继续运行。
- 输入框中已有草稿时，自动化不会覆盖或点击发送。可直接使用旺旺原生发送按钮手动回复。
- 「恢复自动」保留当前问答项，重新建立历史基线，等待下一条新回复。它不会把你的手动对话认定为该问题已经通过。
- 关闭插件侧栏、关闭会话标签页或断开本地服务会暂停相应自动化。恢复必须由你明确操作。
- 如果消息发送结果不确定，到真实会话核对，再使用侧栏的「已确认问题发出」或「确认未发出」。不会自动重复发送。
- 登录、验证码和风险验证由你在 Chrome 手动处理；不自动登录、不重试绕过验证。

## 模型、并发和权限

模型密钥只留在本机服务内存。插件不申请 cookies、debugger 或 nativeMessaging 权限；仅操作 1688 页面并连接本机 127.0.0.1 服务。多个会话交替处理，最多两个页面读取同时执行；实际点击发送保持串行，模型分析复用本机并发工作池。

轮询不会刷新正在编辑的旺旺页面；它只重用页面已有的会话历史读取请求。搜索和消息不会由远程代码执行。发送仅限你明确授权的固定问题、固定澄清及逐条批准的文字。当前模式不包含购物车、下单、付款或站外联系。供应商及其智能客服回复只作为初筛自述，证书与资质需人工核验。

开发验证：安装 Chrome for Testing 后运行 `pnpm test:extension`。该检查使用隔离的 5 家供应商页面和本机模拟模型，验证并行分析、原生发送、接管/手动回复及关闭侧栏暂停，不联系真实商家。真实 1688 页面改版、登录或验证仍需在你的 Chrome 中核对。

Chrome 加载方法：[官方说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。
