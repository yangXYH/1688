Chrome 可见自动化

在真实旺旺里回复，随时接管。

插件使用你当前 Chrome 的 1688 登录状态。每家供应商保留一个真实会话标签页，收发消息回到原生旺旺；本机服务负责模型判断。

  1. 在常用 Google Chrome 中登录 1688。
  2. 地址栏输入 chrome://extensions，打开「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择：
    正在读取插件目录…
  4. 点击插件图标打开侧栏，连接本机服务，核对买家账号。
  5. 输入关键词并搜索，选择多家商品，核对话术后启动。

你在会话里点击或打字时，会暂停该家的自动操作。其他会话继续运行。关闭插件侧栏则暂停自动化。

下载插件 ZIP（需先解压） · 返回本机服务

首次加载必须通过 Chrome 自己的扩展管理界面完成。插件不读取或导出 Cookie，不包含下单与付款。
